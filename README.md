# dengue cross-reactivity model for serotype-specific FOI
## DATA
### Raw data
`vietnam_serosurvey.csv`: The serological data in Vietnam, accessed from https://doi.org/10.1371/journal.pntd.0012568 (Phuong et al, 2024). 

### Preprocessed data for Bayesian model implementation 
`stan_data_StatusModel.rds`: input data for the implementation of status-based model (generated by `preprocess_stan_data_StatusModel.R`).
`stan_data_TitreModel.rds`: input data for the implementation of titre-incorporated model (generated by `preprocess_stan_data_TitreModel.R`).

### Posterior estimates, which are also the data used for figure generation
`cross_est_vn_StatusModel.rds`: posterior estimates of cross-reactivity pattern between dengue serotypes from the status-based model.
`cross_est_vn_TitreModel.rds`: posterior estimates of cross-reactivity pattern between dengue serotypes from the titre-incorporated model.
`foi_est_vn_StatusModel.rds`: posterior estimates of serotype-specific force of infection from the status-based model.
`foi_est_vn_TitreModel.rds`: posterior estimates of serotype-specific force of infection from the titre-incorporated model.
`prevalence_est_StatusModel.rds`: posterior estimates of population historical infection prevalence and seroprevalence from the status-based model.
`prevalence_est_TitreModel.rds`: posterior estimates of population historical infection prevalence and seroprevalence from the titre-incorporated model.
`susceptibility_est_StatusModel.rds`: posterior estimates of population susceptible proportion from the status-based model.
`susceptibility_est_TitreModel.rds`: posterior estimates of population susceptible proportion from the titre-incorporated model. 
`infec_history_est_TitreModel.rds`: posterior estimates of individual-level infection history, from the titre-incorporated model (not applicable for status-based model).
`titre_distribution_est_TitreModel.rds`: posterior estimates of titre distribution across different infection history (not applicable for status-based model).

### Simulation data
`simulate_value_cross_reactivity.rds`: the simulated value of dengue serotype cross-reactivity pattern. 
`simulate_value_foi_highendemic.rds`: the simulated value of dengue serotype transmission under high-endemic setting. 
`simulation_crossest_highendemic_periodic_complete.rds`: posterior estimates of cross-reactivity pattern in simulation study under periodic sampling using complete data, in high-endemic setting. 
`simulation_crossest_highendemic_periodic_subsettested.rds`: posterior estimates of cross-reactivity pattern in simulation study under periodic sampling using subset tested data, in high-endemic setting.
`simulation_foiest_highendemic_periodic_complete.rds`: posterior estimates of force of infection in simulation study under periodic sampling using complete data, in high-endemic setting.
`simulation_foiest_highendemic_periodic_subsettested.rds`: posterior estimates of force of infection in simulation study under periodic sampling using subset tested data, in high-endemic setting.


## Codes
`preprocess_stan_data_StatusModel.R`: the code generating `stan_data_StatusModel.rds`.
`preprocess_stan_data_TitreModel.R`: the code generating `stan_data_TitreModel.rds`.

`StatusModel_implement.R`: the code implementing the status-based model.
`TitreModel_implement.R`: the code implementing the titre-incorporated model.

`Figurecode.R`: the code generating the figures in the main manuscript.
